# cron-fr

**Traduit une expression cron en français clair.**

Zéro dépendance · Node.js 18+ · Windows, macOS, Linux.

## Utiliser tout de suite (sans rien installer)

```bash
npx github:zrk-lol/cron-fr "30 8 * * 1-5"
```

## Installer la commande `cron-fr`

```bash
npm install -g github:zrk-lol/cron-fr
cron-fr "30 8 * * 1-5"
```
